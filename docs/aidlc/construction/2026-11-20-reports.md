## Design

### Services (`backend/apps/reports/services.py`, no models)

- `range_from(params, *, today=None) -> ReportRange`: `from`/`to` as `YYYY-MM-DD` (default: the 30 days ending
  today), optional `hospital` id. Refuses (`ReportQueryError`, 400) a malformed date, `to` before `from`, more than
  366 days, or an unknown hospital. Day bounds are Karachi midnights in UTC, as in `apps.audit.services`.
- `requests_report(r)`: cases created in the range (`EmergencyRequest.created_at`), counted by severity and by current
  status; needs by resource type (needs and units asked for); allocations made in the range (`Allocation.at`) by
  resource type. The hospital filter is the case's hospital.
- `fulfilment_report(r)`: per case, the first `RequestStatusChange` to *fulfilled*; cases whose first one falls in the
  range. Minutes from `created_at` to it: count, median, average, 90th percentile (nearest rank), overall and by
  severity. Plus cases created in the range that never reached fulfilled, by current status.
- `wastage_report(r)`: blood units whose expiry fell in the range and is past, and were never issued or discarded
  (expired, or still on the shelf past expiry); units discarded in the range (`status_since`). Rows by hospital,
  group and component.
- `build(r)`: the three reports plus the range and hospital, as one dict (the API's JSON).

### Export (`backend/apps/reports/exports.py`)

- `to_csv(report) -> str`: one section per report (title row, header row, data rows, blank line). Cells that a
  spreadsheet would run as a formula are prefixed with `'`, as in B10.
- `to_pdf(report) -> bytes`: `fpdf2` (pinned in `requirements.txt`), A4 portrait, Helvetica, a title, the range and
  filter, one table per report. Text outside Latin-1 is replaced, since the core fonts can't draw it.

### API (`/api/reports/`)

| Method | Path | Does |
|---|---|---|
| GET | `/api/reports/?from=&to=&hospital=` | The three reports as JSON. |
| GET | `/api/reports/export/?format=csv\|pdf&from=&to=&hospital=` | The file, `reports-<from>-to-<to>.<ext>`; writes `report.exported`. Unknown format: 400. |

Both: `module_permission("reports")`. New module `reports`: admin `view` (backend `ACCESS`, frontend `roles.ts`,
`docs/architecture/api-contracts.md`). The overdue-case sweep runs first, as the command centre does, so statuses are
current.

### Frontend

- `src/api/reports.ts`: types, `getReports(filters)`, `reportExportUrl(filters, format)`. Mocked in `mockApi.ts`.
- `src/pages/staff/ReportsPage.tsx`: From/To dates, hospital select (from `/api/hospitals/`), **Show**, three tables,
  **Export CSV** and **Export PDF** links. Route `/staff/reports`, nav entry **Reports** (admin only).
